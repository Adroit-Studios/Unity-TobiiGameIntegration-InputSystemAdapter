## [1.0.1] - 2026-06-16

### Changes

- Moved helper scripts to a new namespace to avoid conflicting with other versions
- General project cleanup and organization
- Initial Full version release

## [0.1.0] - 2026-06-08

### Added

- Initial package setup for Unity Package Manager distribution.
- Virtual Input System devices for:
  - Tobii gaze tracking
  - Tobii head angle tracking
  - Tobii head position tracking
- Layout registration helpers for TGI virtual devices.
- Demo content for validation and integration testing.
- Package metadata and documentation files.
